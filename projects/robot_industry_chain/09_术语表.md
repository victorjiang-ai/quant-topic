## 01_动力关节系统

| 术语 | 英文 | 定义 |
|---|---|---|
| **谐波减速器** | Harmonic Drive | 利用柔轮弹性变形实现大减速比的精密减速器，用于人形机器人上肢等关节。 |
| **RV减速器** | Rotate Vector Reducer | 摆线针轮减速器，高刚性、高扭矩，用于人形机器人下肢等重负载关节。 |
| **行星减速器** | Planetary Gearbox | 利用行星齿轮实现减速的减速器，精度与成本平衡良好。 |
| **无框力矩电机** | Frameless Torque Motor | 去除外壳的高扭矩密度电机，直接与减速器集成，适合关节。 |
| **空心杯电机** | Coreless DC Motor | 无铁芯的直流电机，响应快、低惯量，适合灵巧手等小关节。 |
| **伺服驱动器** | Servo Drive | 驱动伺服电机的控制器，实现精确的位置、速度、扭矩控制。 |
| **行星滚柱丝杠** | Planetary Roller Screw | 高效的直线传动装置，用于直驱或线性关节。 |
| **滚珠丝杠** | Ball Screw | 利用滚珠的滚动摩擦实现直线传动的装置。 |
| **直线导轨** | Linear Guide | 提供直线导向的精密机械部件，用于直线运动。 |
| **轴承** | Bearing | 支撑旋转轴的精密机械部件。 |

## 02_感知系统

| 术语 | 英文 | 定义 |
|---|---|---|
| **六维力矩传感器** | 6-Axis Force/Torque Sensor | 同时测量3个方向力与3个方向力矩的传感器，用于力反馈控制。 |
| **触觉传感器** | Tactile Sensor | 测量接触力与纹理的传感器，用于灵巧手。 |
| **电子皮肤** | E-Skin | 柔性的仿生皮肤，可分布大量触觉传感器。 |
| **编码器** | Encoder | 测量旋转角度或直线位移的传感器，用于关节位置反馈。 |
| **IMU** | Inertial Measurement Unit | 惯性测量单元，包含加速度计与陀螺仪，测量姿态与加速度。 |
| **机器视觉** | Machine Vision | 利用摄像头与视觉算法实现环境感知。 |
