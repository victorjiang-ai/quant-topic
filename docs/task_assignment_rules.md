# Claude Code + Trae SOLO 任务分配规则

## 📋 任务分类体系

### 🔴 Tier 1 - Claude Code 专属任务

**特征**:
- 涉及架构设计
- 需要深度算法设计
- 多模块协调
- 性能优化
- 复杂重构

**具体任务类型**:

1. **架构设计**
   - 新系统架构设计
   - 模块间关系重构
   - 数据流设计
   - 技术选型决策

2. **核心算法**
   - 题材热度算法优化
   - 龙头股识别算法改进
   - 信号生成策略设计
   - 回测框架设计

3. **性能优化**
   - 数据采集性能优化
   - 模型计算性能优化
   - 并发处理设计
   - 缓存机制设计

4. **复杂重构**
   - 跨模块重构
   - 接口重构
   - 数据结构重构
   - 代码架构重构

**判断标准**:
- 修改影响 > 3 个模块
- 涉及核心算法逻辑
- 需要架构决策
- 性能优化需求

---

### 🟡 Tier 2 - Trae SOLO 主导任务

**特征**:
- 单模块功能开发
- 明确需求
- 标准实现
- 测试编写
- 文档维护

**具体任务类型**:

1. **功能开发**
   - 单文件功能实现
   - 工具函数开发
   - 配置文件修改
   - 数据处理脚本

2. **测试编写**
   - 单元测试
   - 集成测试
   - 测试用例设计
   - 测试覆盖率提升

3. **Bug 修复**
   - 单模块 Bug 修复
   - 配置问题修复
   - 数据问题修复
   - 界面问题修复

4. **文档维护**
   - README 更新
   - API 文档编写
   - 使用指南编写
   - 配置说明更新

5. **数据处理**
   - 数据采集脚本
   - 数据清洗脚本
   - 数据转换脚本
   - 数据备份脚本

**判断标准**:
- 修改范围 ≤ 1 个模块
- 需求明确、实现标准
- 不涉及架构变更
- 代码量 < 200 行

---

### 🟢 Tier 3 - 协作任务

**特征**:
- 需要双方配合
- 分阶段完成
- 需要交接

**具体任务类型**:

1. **新模块开发**
   - Claude Code: 设计架构、定义接口
   - Trae SOLO: 实现功能、编写测试

2. **复杂功能**
   - Claude Code: 核心算法设计
   - Trae SOLO: 功能实现、边界处理

3. **系统优化**
   - Claude Code: 性能分析、优化方案
   - Trae SOLO: 实施优化、测试验证

**协作流程**:
1. Claude Code 完成设计阶段
2. 创建交接笔记
3. Trae SOLO 接手实现阶段
4. 遇到问题反馈给 Claude Code

## 📏 代码量判断标准

### Trae SOLO 可独立完成

- **单文件修改**: < 200 行
- **新增文件**: < 150 行
- **配置修改**: 任意行数
- **测试文件**: < 300 行

### 需 Claude Code 参与

- **单文件修改**: > 200 行
- **新增文件**: > 150 行
- **跨模块修改**: 任意行数
- **架构文件**: 任意行数

## 🔍 任务识别流程

### 1. 任务分析

```
收到任务 → 分析需求 → 判断类型 → 确定负责人
```

### 2. 判断维度

**维度 1: 影响范围**
- 单模块 → Trae SOLO
- 多模块 → Claude Code
- 全系统 → Claude Code

**维度 2: 复杂度**
- 标准实现 → Trae SOLO
- 算法设计 → Claude Code
- 架构设计 → Claude Code

**维度 3: 代码量**
- < 200 行 → Trae SOLO
- > 200 行 → Claude Code
- 不确定 → 先评估

**维度 4: 需求明确度**
- 明确需求 → Trae SOLO
- 需要设计 → Claude Code
- 需要决策 → Claude Code

### Trae SOLO 独立任务

```
1. 理解需求
2. 查看相关代码
3. 实现功能
4. 编写测试
5. 更新文档
6. 提交代码
```

### Claude Code 独立任务

```
1. 分析需求

3. 实现核心逻辑

```

### 协作任务

```

1. 架构设计
2. 接口定义

1. 功能实现
2. 边界处理
3. 测试编写
4. 文档更新

阶段 3 (验证):
1. Claude Code 审查
2. Trae SOLO 修复
3. 最终验收
```

## ⚠️ 任务转交规则

### Trae SOLO → Claude Code

**触发条件**:
- 发现架构问题
- 需要算法优化
- 跨模块依赖
- 性能瓶颈

**转交流程**:
1. 在 `docs/handover_notes.md` 记录问题
2. 描述问题详情
3. 提供初步分析
4. 等待 Claude Code 处理

### Claude Code → Trae SOLO

**触发条件**:
- 设计阶段完成
- 接口已定义
- 核心逻辑已实现
- 需要功能完善

**转交流程**:
1. 更新 `docs/handover_notes.md`
2. 说明已完成部分
3. 列出待完成部分
4. 提供实现建议
